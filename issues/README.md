# Issues — 実装ロードマップ

仕様は `../spec.md`(v2.0)が正。各 issue は仕様のセクションを根拠に持つ。

## 運用ルール

- **issue 番号 = 実装順**。001 → 022 の順に、依存する issue が完了してから着手する
- 状態は 3 値: ⬜ 未着手 / 🔄 実装中 / ✅ 完了(進捗表と issue ファイルの両方で管理)
- v1(001〜010)完了で「受け入れ条件」(spec.md §9)を満たすこと。011 以降は任意の拡張
- 各 issue のテスト観点は Playwright(TypeScript)の spec に反映する(`e2e/` に配置)
