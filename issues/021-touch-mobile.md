# 021: モバイル / タッチ操作

**ラベル**: feature, roadmap
**ステータス**: ⬜ 未着手
**関連仕様**: spec.md §8.11

## 概要
タッチ操作とレスポンシブな縦型レイアウトに対応する。

## 要求
- [ ] スワイプで左右移動、タップで回転、ダブルタップでハードドロップ、専用ボタンでホールド
- [ ] レスポンシブな縦型レイアウト(盤面上部にキュー / ホールドを横並び)
- [ ] 誤タップ防止のためボタンに十分なタップ領域(最小 44px)を確保する
- [ ] 画面の向き変更でゲーム状態が破綻しない

## 検収基準
- [ ] タッチのみで 1 周のプレイが完走できる
- [ ] 一般的なスマホ画面幅で盤面全体が操作できる
- [ ] スワイプとタップが同時に発火した際の誤動作がない
