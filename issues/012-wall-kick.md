# 012 SRS + ウォールキック

- 区分: roadmap(§10.2) / 依存: 011 / 状態: ⬜ 未着手
- 仕様根拠: spec.md §10.2(§3.7 置き換え)

## ゴール

naive 回転を廃し、SRS 準拠の回転(キック表)にする。

## 実装内容

- [ ] SRS の回転状態とキック表(I / L / J / S / Z / T)を実装
- [ ] 回転時、本来位置 → キック順で空き位置を探す。全失敗で回転無効
- [ ] 回転状態は `0..3`(013 の反時計回りと整合する状態番号を使う)

## テスト(Playwright)

- [ ] 壁際・床際の T / L / J の回転が成功する(旧実装で失敗したケース)
- [ ] I が縦 → 横で壁へ寄る
- [ ] 狭い隙間での失敗時は回転前の状態を保持

## 完了条件

キック成功・失敗ケースの e2e が green。
