# 005: ライン消しとアニメーション

**ラベル**: feature, v1

**ステータス**: 🔄 実装中（検出・消去・シフトは 002 実装時に反映、フラッシュアニメーションは未実装）

**関連仕様**: spec.md §2.4

## 概要
満行の検出・消去・落下シフトと、消去時のアニメーションを実装する。

## 進捗
- 満行検出・消去・上段シフト（複数行同時）は 002（Game Loop）の実装時に反映済み（`src/game.ts` の `lockPiece`）。残: フラッシュアニメーションとアニメーション中の入力制御。

## 要求
- [x] 水平 1 行が埋まった行を検出し、消去して上の行を下へシフトする
- [x] 複数行(最大 4 行)の同時消しに対応する
- [ ] 消去時にフラッシュアニメーション(約 250ms)を表示する
- [ ] アニメーション完了後にのみゲーム(次のピース出現・落下)を再開する
- [ ] アニメーション中は操作入力を受け付けない

## 検収基準
- [x] 1 行が消え、上の行が正確に下へ落ちる
- [x] 2〜4 行の同時消しが一度の操作で扱われる
- [ ] フラッシュ後に次のピースが出現し、アニメーション最中に新しいピースが出ない
