# 005: ライン消しとアニメーション

**ラベル**: feature, v1

**ステータス**: ✅ 完了

**関連仕様**: spec.md §2.4

## 概要
満行の検出・消去・落下シフトと、消去時のアニメーションを実装する。

## 進捗
- 満行検出・消去・上段シフト（複数行同時）は 002（Game Loop）の実装時に反映済み。
- 本 Issue で **2 フェーズ化**し、フラッシュアニメーションとアニメーション中の入力制御を実装:
  - `src/game.ts`: ロックと解決を分離。`lockPiece`（ロック＋満行検出 → `clearingRows`）/ `resolveClear`（消去・シフト・スコア・次ピース出現）/ `completeLock`（直結合成）/ `dropToBottom`。
  - `src/App.tsx`: ロック発生時、満行があれば `flash` 状態で約 250ms 表示 → 完了後に `resolveClear` の結果へ反映（次のピース出現・落下再開）。`flash` 中は重力と入力（移動・回転・ソフト/ハードドロップ）を無効化。
  - `src/index.css`: `tetris-clear` キーフレーム（白く光って溶けて消える、250ms）。

## 要求
- [x] 水平 1 行が埋まった行を検出し、消去して上の行を下へシフトする
- [x] 複数行(最大 4 行)の同時消しに対応する
- [x] 消去時にフラッシュアニメーション(約 250ms)を表示する
- [x] アニメーション完了後にのみゲーム(次のピース出現・落下)を再開する
- [x] アニメーション中は操作入力を受け付けない

## 検収基準
- [x] 1 行が消え、上の行が正確に下へ落ちる
- [x] 2〜4 行の同時消しが一度の操作で扱われる
- [x] フラッシュ後に次のピースが出現し、アニメーション最中に新しいピースが出ない

  - 満行解決: `resolveClear` が消去・上段シフト・スコア（40/100/300/1200 × レベル）・レベル積算・次ピース出現・`clearingRows` リセットを検証。
  - 2 フェーズ: `completeLock = resolveClear ∘ lockPiece` の等価性（次ピースの乱数を除く）。
  - ハードドロップ＋ライン消し: 着地ロックで満行 → 消去・ライン得点・落下得点の合計（52 点）。
