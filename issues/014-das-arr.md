# 014: DAS / ARR 入力カスタマイズ

**ラベル**: feature, roadmap

**ステータス**: ⬜ 未着手

**関連仕様**: spec.md §8.4

## 概要
長押し反復をエンジン側で実装し、DAS / ARR を調整可能にする。

## 進捗
- 未着手

## 要求
- [ ] 長押し反復をエンジン側で実装する(ブラウザのキー自動反復に依存しない)
- [ ] DAS(初回待ち時間)と ARR(反復間隔)をスライダーで調整可能にする
- [ ] 値を `tetris.input` に `{ das: number, arr: number }` として保存し、リロード後も維持する
- [ ] 既定の値(例: DAS 170ms / ARR 40ms)をリセット操作で復元する

## 検収基準
- [ ] 長押しで DAS 後に ARR 間隔で一定速度で移動する
- [ ] 数値変更が即時に操作感へ反映される
- [ ] 左右同時同時押し等の入力競合でも予期しない跳ね返りがない
