# 014 DAS / ARR

- 区分: roadmap(§10.4) / 依存: 013 / 状態: ⬜ 未着手
- 仕様根拠: spec.md §10.4(§3.6 補完)

## ゴール

左右キーの反復入力を OS ではなく自前で制御し、設定できるようにする。

## 実装内容

- [ ] DAS(初期遅延)/ ARR(反復間隔)の既定値と内部制御
- [ ] 設定 UI(スライダー等)と `localStorage` 保存
- [ ] OS 自動反復を無効化するため keyup まで自前反復(簡易: OS 反復に重ねない)

## テスト(Playwright)

- [ ] `→` 長押しで一定遅延後、設定間隔で連続移動する
- [ ] keyup 後は即移動停止、1 キー 1 移動の挙動と両立

## 完了条件

反復制御 timing を保証つきの e2e で検証(例: fake timer 相当の間隔検証)。
