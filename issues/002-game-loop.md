# 002 ゲームループ(重力・ロック)

- 区分: v1 / 依存: 001 / 状態: ⬜ 未着手
- 仕様根拠: §3.3、§3.4、§3.5

## ゴール

7 バッグ方式でピースが出現し、一定間隔で落下し、接地したらロックされて次のピースが出る。

## 実装内容

- [ ] `bag.ts`: 7 バッグ生成とシャッフル、消費・再生成
- [ ] `useGame.ts`: 落下間隔ごとの重力ティック(この時点でレベル 1 = 800ms 固定)
- [ ] 接地(下へ移動不可)で即時ロック、盤面に固定、次のピースを出現
- [ ] 出現位置が埋まっている場合の状態「ブロックアウト」の内部判定(表示は 008 で実装)

## テスト(Playwright)

- [ ] 800ms ごとに `cell` の埋まり位置が 1 行下がる
- [ ] 14 個連続で出現させ、同一種の出現回数が最大 3 回に収まる(7 バッグ保証)
- [ ] 最下段到達でロックされ、次のピースが上部に出現する

## 完了条件

ピースが盤面に積み上がる e2e が green。
