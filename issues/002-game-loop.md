# 002: 落下(ゲームループ)

**ラベル**: feature, v1
**ステータス**: ⬜ 未着手
**関連仕様**: spec.md §2.2

## 概要
ピースの落下ループを実装し、ロックと出現を繰り返す。

## 要求
- [ ] 落下間隔(§2.5)ごとにピースを 1 セル下方へ移動する
- [ ] 下方への移動ができなくなった時点でロックし、新しいピースを出現させる
- [ ] 落下間隔は現在のレベルに従う
- [ ] 新しいピースが出現時点で衝突した場合はゲームオーバーとして扱う

## 検収基準
- [ ] ピースが落下し、ロックされ、次のピースが連続して出現する
- [ ] スタックが上端まで積み上がるとゲームオーバーになる
- [ ] 落下にカクつきがなく、60fps を保てる
