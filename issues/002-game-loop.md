## 概要
ゲームループ（ピースの落下・ロック・ゲームオーバー判定）を実装します。

- [ ] 回転時の壁打ち（Wall Kick）→ v1 スコープ外。[012](012-wall-kick.md)（spec §8.2）へ振替。

## 実装内容
- 重力: `setInterval` で `dropIntervalMs(level)` ごとに 1 セル下方へ落下、できなければロック
- ロック: 固定セル書き込み → 満行検出・消去 → 上段シフト → スコア/レベル更新 → 次ピース移行
- ゲームオーバー: 出現位置が既存セルと衝突したら終了（`isGameOver`）
- キー: `←/→` 移動、`↑` 回転、`↓` ソフトドロップ、`Space` ハードドロップ / スタート、`R` リスタート
- 画面: ダークモード対応、NEXT プレビュー、スコア/レベル/ライン表示、Ready / Game Over オーバーレイ
