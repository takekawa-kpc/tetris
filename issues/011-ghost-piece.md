# 011 ゴーストピース

- 区分: roadmap(§10.1) / 依存: 010 / 状態: ⬜ 未着手
- 仕様根拠: spec.md §10.1

## ゴール

ハードドロップの着地位置を半透明で常時表示する。

## 実装内容

- [ ] 現在位置から盤面下端・最上部固定セルまでの落下可能距離を算出
- [ ] 着地形状を薄い輪郭(または低透過度)で描画。`ghost` testid を付与
- [ ] 移動・回転・ホールドに追従し、アニメーション対象にしない

## テスト(Playwright)

- [ ] `Space` 前のゴースト位置とハードドロップ後の位置が一致
- [ ] ゴーストが既存ブロック手前で止まる

## 完了条件

ゴースト位置の e2e が green。
