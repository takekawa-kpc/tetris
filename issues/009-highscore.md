# 009: ハイスコアの永続化

**ラベル**: feature, v1
**ステータス**: ⬜ 未着手
**関連仕様**: spec.md §2.8, §3.1, §5

## 概要
ハイスコアを `localStorage` に保存し、常時表示する。

## 要求
- [ ] `tetris.highScore` にハイスコアを JSON number で保存する
- [ ] 右パネルにハイスコアを常時表示する
- [ ] ゲーム終了時にスコアがハイスコアを上回った場合、更新して「新記録」の表示を行う
- [ ] JSON パース失敗時は 0 にフォールバックし、ゲームがクラッシュしない

## 検収基準
- [ ] ハイスコア更新後、リロードしても保持される
- [ ] 低いスコア終了でハイスコアが下がることはない
- [ ] 新記録時に「新記録」表示が出る
- [ ] `tetris.highScore` に不正な値を入れてもゲームが正常に起動する
