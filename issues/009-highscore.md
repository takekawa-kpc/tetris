# 009: ハイスコアの永続化

**ラベル**: feature, v1

**ステータス**: ⬜ 未着手

**関連仕様**: spec.md §2.8

## 概要
ハイスコアを `localStorage` に保存し、常時表示する。

## 進捗
- 未着手

## 要求
- [ ] `tetris.highScore` にハイスコアを JSON number で保存する
- [ ] 右パネルにハイスコアを常時表示する
- [ ] ゲームオーバー時に最終スコアがハイスコアを上回った場合、更新して「新記録」の表示を行う
- [ ] JSON パース失敗時は 0 にフォールバックし、ゲームがクラッシュしない

## 検収基準
- [ ] ハイスコア更新後、リロードしても保持される
- - [ ] 0 で始まり、 0 でないスコアが 0 を上回ったらハイスコアを更新
- [ ] 0 でない場合、ハイスコアが 0 でなくなる
