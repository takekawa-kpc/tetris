# 009 ハイスコア

- 区分: v1 / 依存: 008 / 状態: ⬜ 未着手
- 仕様根拠: §3.12、§5.3、§6(localStorage 失敗時の耐性)

## ゴール

ゲーム結果をハイスコアとして保存し、常時表示する。

## 実装内容

- [ ] `localStorage` の `tetris.highScore` に保存・復元(JSON number)
- [ ] パネルに常時表示(`highscore`)、更新時に「新記録」表示
- [ ] 保存失敗(無効・いっぱい)は握りつぶしてプレイ継続

## テスト(Playwright)

- [ ] ゲームオーバー後にスコアが保存され、リロード後も表示される
- [ ] 低スコアでは上書きされない
- [ ] `localStorage.setItem` を失敗させてもゲームが続く

## 完了条件

永続化の e2e が green。
