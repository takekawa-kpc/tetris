# 006: スコアとレベル(速度アップ)

**ラベル**: feature, v1

**ステータス**: 🔄 実装中（加算表・レベル・落下速度は 002 実装時に反映、レベルアップの視覚フィードバックは未実装）

**関連仕様**: spec.md §2.5

## 概要
加算表に基づくスコア計算と、レベル・落下速度の更新を実装する。

## 進捗
- 加算表・レベル上昇（上限 15）・落下間隔・常時表示は 002（Game Loop）の実装時に反映済み（`src/game.ts` / `src/App.tsx`）。残: レベルアップ時の視覚フィードバック。

## 要求
- [x] §2.5 の加算表(40 / 100 / 300 / 1200 × レベル)でスコアを加算する
- [x] レベルを 1 で開始し、消し行数の累計 10 行ごとに +1(上限 15)する
- [x] レベルに応じて落下間隔を `max(100, round(800 × 0.85^(level - 1)))` ms で計算し、即座に適用する
- [x] スコア・レベル・消し行数を常時表示する
- [ ] レベルアップ時に視覚的なフィードバック(例: 一瞬の高ライト表示)を行う

## 検収基準
- [x] 各ライン数・ドロップ種別の得点が加算表と一致する（※ソフト/ハードドロップの加算は 004）
- [x] 10 行でレベル 2 になり、落下が明確に速くなる
- [x] レベル 15 を超えず、落下間隔は 100ms を下回らない
