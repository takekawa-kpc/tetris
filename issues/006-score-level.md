# 006: スコアとレベル(速度アップ)

**ラベル**: feature, v1

**ステータス**: ✅ 完了

**関連仕様**: spec.md §2.5

## 概要
加算表に基づくスコア計算と、レベル・落下速度の更新を実装する。

## 進捗
- 加算表・レベル上昇（上限 15）・落下間隔・常時表示は 002（Game Loop）の実装時に反映済み。
- 本 Issue で **レベルアップ時の視覚フィードバック**を実装:
  - `src/game.ts`: `levelForLines`（消し行数→レベル、上限 15）を純粋関数として抽出し `resolveClear` が使用。`isLevelUp(before, after)` でレベルアップを検出。
  - `src/App.tsx`: ロック解決時、`isLevelUp` が true なら新レベルを `levelUp` 状態として約 900ms 表示（「レベルアップ！ Lv.N」バナー ＋ レベル値の高ライト）。
  - `src/index.css`: `level-up-banner`（浮かび上がる）と `level-glow`（一瞬光る）キーフレーム。

## 要求
- [x] §2.5 の加算表(40 / 100 / 300 / 1200 × レベル)でスコアを加算する
- [x] レベルを 1 で開始し、消し行数の累計 10 行ごとに +1(上限 15)する
- [x] レベルに応じて落下間隔を `max(100, round(800 × 0.85^(level - 1)))` ms で計算し、即座に適用する
- [x] スコア・レベル・消し行数を常時表示する
- [x] レベルアップ時に視覚的なフィードバック(例: 一瞬の高ライト表示)を行う

## 検収基準
- [x] 各ライン数・ドロップ種別の得点が加算表と一致する（※ソフト/ハードドロップの加算は 004）
- [x] 10 行でレベル 2 になり、落下が明確に速くなる
- [x] レベル 15 を超えず、落下間隔は 100ms を下回らない

## 検証
- テスト `e2e/06-score-level.test.ts`（Playwright / TypeScript）24 件を追加:
  - 加算表: 40/100/300/1200 × レベル（レベル 1・3・0 行）、`scoreForClear`。
  - レベル進行: `levelForLines` の 10 行ごと +1 と上限 15（0/9/10/19/20/90/99/100/140/149/150/9999 行）。
  - 落下間隔: `dropIntervalMs` のレベル 1 = 800ms、短縮、100ms 下限（レベル 15/16/99）。
  - レベルアップ検出: `isLevelUp`（上昇 true / 不変 false / 下降 false）。
  - 実機: `completeLock` によるレベル 1→2（レベルアップ判定 true）、10 行未達でレベルアップなし、レベル 15 超過なし。
