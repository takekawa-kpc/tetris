# 022: オンラインランキング

**ラベル**: feature, roadmap
**ステータス**: ⬜ 未着手
**関連仕様**: spec.md §8.12

## 概要
バックエンド API によるスコア送信とランキング表示を実装する。

## 要求
- [ ] ゲーム終了後、スコアと名前を API に送信する
  - `POST /scores { name, score, lines, level, mode, date }`
- [ ] `GET /scores?mode=&limit=` でランキング一覧を取得・表示する
- [ ] オフライン / API 失敗時はエラー表示し、ゲーム体験を妨げない

## 検収基準
- [ ] 送信したスコアがランキングに現れる(順位の並びが正しい)
- [ ] モード切替でランキングの内容が切り替わる
- [ ] ネットワークエラーでもゲーム自体は正常に動作する
