# 015: サウンド / BGM

**ラベル**: feature, roadmap
**ステータス**: ⬜ 未着手
**関連仕様**: spec.md §8.5

## 概要
効果音と BGM を Web Audio API で実装する。

## 要求
- [ ] ロック・ライン消し・レベルアップ・ゲームオーバーの効果音を再生する
- [ ] BGM の再生とミュート切替ボタンを提供する
- [ ] 初回のユーザー操作後にのみ音声を再生する(ブラウザ制約)
- [ ] 音量・ミュート状態を `tetris.settings` に保存し、リロード後も維持する

## 検収基準
- [ ] 各イベント時に効果音が遅延なく再生される
- [ ] ミュート切替が即座に反映され、リロード後も維持される
- [ ] タブ非表示時やエラーでゲーム自体が止まることはない
