# 008: ポーズとゲームオーバー

**ラベル**: feature, v1
**ステータス**: ⬜ 未着手
**関連仕様**: spec.md §2.7

## 概要
ポーズ / ゲームオーバー / リスタートの状態遷移とオーバーレイ UI を実装する。

## 要求
- [ ] `P` または `Esc` でポーズ切替し、盤面を暗幕化した「ポーズ中」オーバーレイを表示する
- [ ] ポーズ中は落下・ライン消し・スコアが完全に停止する
- [ ] ゲームオーバー時に最終スコアを表示し、「もう一度プレイ」ボタン / `R` キーでリスタートする
- [ ] リスタートで盤面・スコア・レベル・消し行数・キューを初期化する(ハイスコアは保持)
- [ ] 開始前は Ready 状態で「Space でスタート」オーバーレイを表示し、`Space` で開始する

## 検収基準
- [ ] ポーズ → 復帰で、中断した状態から正確に再開できる
- [ ] ゲームオーバーが正しくトリガーされ、最終スコアとリスタート導線が表示される
- [ ] リスタート後に初期状態からプレイでき、スコアは 0 から始まる
