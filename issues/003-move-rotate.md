# 003: 移動と回転

**ラベル**: feature, v1

**ステータス**: ✅ 完了（コア範囲: 移動・回転・衝突拒否。smooth 長押しは [014](014-das-arr.md)、壁打ちは [012](012-wall-kick.md) に分離）

**関連仕様**: spec.md §2.3

## 概要
左右移動と時計回り回転を実装し、衝突判定を行う。

## 進捗
- 002（Game Loop）で基本実装済み。
- 003 として `src/game.ts` にテストしやすい `move(state, dx, dy)` / `rotate(state, dir)` を抽出し、`src/App.tsx` のキー処理へ配線済み。
- 残（本 Issue 範囲外）: 長押し smooth 調整（[014](014-das-arr.md)）、壁打ち（[012](012-wall-kick.md)）。

## 要求
- [x] `←` / `→` で 1 セルずつ左右に移動する
- [x] 移動系はキー長押しでブラウザのキー自動反復が有効になる
- [x] `↑` で時計回りに 90° 回転する(4 つの回転状態)
- [x] 盤面外・固定セルと衝突する移動・回転は無効(ピースは元の位置に残る)
- [x] 移動・回転の反映は入力から 1 フレーム以内

## 検収基準
- [x] ピースを盤面の左右端まで動かせ、端を越えて動けない
- [x] 壁や角に接した状態でも回転が正しく(または無効に)処理される（※壁打ちは 012）
- [ ] 長押しによる連続移動が smooth に動作する（→ [014](014-das-arr.md) の DAS/ARR 調整、本 Issue 範囲外）

## 検証
- `e2e/03-move-rotate.test.ts`（Playwright + TypeScript）で移動 9 件・回転 10 件を確定的に検証済み。
  - 左右下 1 セル移動 / 回転状態不変
  - 左右端の境界（`null` 返却、端まで連続移動で停止）
  - 固定セルとの衝突拒否（移動・回転）
  - 時計回り / 反時計回り / 4 回転で元に戻る / O の identity / I の横↔縦 / ボックス範囲
  - ゲームオーバー時の無効化
- 実行: `npx playwright test`（全 39 件通過）、`npx tsc -b`（エラーなし）
