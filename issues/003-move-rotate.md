# 003: 移動と回転

**ラベル**: feature, v1

**ステータス**: ⬜ 未着手

**関連仕様**: spec.md §2.3

## 概要
左右移動と時計回り回転を実装し、衝突判定を行う。

## 進捗
- 未着手

## 要求
- [ ] `←` / `→` で 1 セルずつ左右に移動する
- [ ] 移動系はキー長押しでブラウザのキー自動反復が有効になる
- [ ] `↑` で時計回りに 90° 回転する(4 つの回転状態)
- [ ] 盤面外・固定セルと衝突する移動・回転は無効(ピースは元の位置に残る)
- [ ] 移動・回転の反映は入力から 1 フレーム以内

## 検収基準
- [ ] ピースを盤面の左右端まで動かせ、端を越えて動けない
- [ ] 壁や角に接した状態でも回転が正しく(または無効に)処理される
- [ ] 長押しによる連続移動が smooth に動作する
