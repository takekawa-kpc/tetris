# 003 移動と回転

- 区分: v1 / 依存: 002 / 状態: ⬜ 未着手
- 仕様根拠: §3.6(矢印)、§3.7

## ゴール

左右移動と時計回り回転がキーボードででき、衝突は無効になる。

## 実装内容

- [ ] `useKeyboard.ts`: `←` `→` `↑` を処理し、デフォルト動作を `preventDefault()` する
- [ ] 移動・回転の衝突判定(盤面外・固定セル)を実装し、無効時は状態不変
- [ ] 回転は §3.7 のボックス内変換(`(r, c) → (c, B-1-r)`)。O は回転無効

## テスト(Playwright)

- [ ] `←`/`→` で 1 キー 1 セル移動、壁・既存ブロックへの移動は無効
- [ ] `↑` 4 回で元の形状に戻る(T・S・Z・J・L・I)
- [ ] 埋まった位置での回転は無効(セル状態が変わらない)

## 完了条件

操作拒否・回転の e2e が green。
