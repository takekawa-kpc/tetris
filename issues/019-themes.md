# 019: テーマとカラーカスタマイズ

**ラベル**: feature, roadmap

**ステータス**: ⬜ 未着手

**関連仕様**: spec.md §8.9

## 概要
盤面・ピースカラーのテーマ切替を実装する。

## 進捗
- 未着手

## 要求
- [ ] 既定 / モノクロ / パステルの複数テーマから選択できる
- [ ] カラーは CSS トークンで定義し、テーマ間で差し替え可能にする
- [ ] 選択を `tetris.theme` キーに保存し、リロード後も維持する
- [ ] ダークモード対応(§4.3)と両立する

## 検収基準
- [ ] テーマ切替で盤面・ピース・パネルのカラーが即座に更新される
- [ ] どのテーマでも 7 種のピースが識別できる
- [ ] 選択がリロード後も保持され、ダークモード追従が維持される
