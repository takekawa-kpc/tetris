# 013: 反時計回り回転とキーカスタマイズ

**ラベル**: feature, roadmap

**ステータス**: ⬜ 未着手

**関連仕様**: spec.md §8.3

## 概要
反時計回り回転キーを追加し、キー割り当てをカスタマイズ可能にする。

## 進捗
- 未着手

## 要求
- [ ] 反時計回り回転キーを追加する(既定: `X`)
- [ ] キー割り当てを UI から変更でき、即座に有効になる
- [ ] 割り当てを `localStorage` の `tetris.keys`(`Record<string, string>`)に保存し、リロード後も維持する
- [ ] 既定の割り当てに戻す(リセット)操作を提供する

## 検収基準
- [ ] 既定キーで反時計回り回転が動作する
- [ ] キー変更後、新旧の割り当てが正しく効く
- [ ] 変更内容がリロード後も保持され、リセットで既定に戻れる
