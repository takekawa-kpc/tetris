# 004: ソフトドロップ / ハードドロップ

**ラベル**: feature, v1

**ステータス**: ✅ 完了（ソフト/ハードドロップの得点加算を実装し、テストで検証済み）

**関連仕様**: spec.md §2.3, §2.5

## 概要
手動での落下操作(ソフトドロップ・ハードドロップ)と得点を実装する。

## 進捗
- 落下・ロックの操作は 002（Game Loop）の実装時に反映済み。
- 004 として `src/game.ts` に `softDrop(state)`（1 セル/1 点）と `hardDrop(state)`（落下セル数 × 2 点）を追加し、`src/App.tsx` の `↓` / `Space` へ配線済み。

## 要求
- [x] `↓` でソフトドロップ: 1 セル下へ移動し、1 セルにつき 1 点加算する
- [x] `Space` でハードドロップ: 着地位置まで即時落下してロックし、落下セル数 × 2 点加算する
- [x] ソフトドロップ中は移動・回転操作も有効
- [x] ハードドロップ後はロック処理が正しい
- [x] ハードドロップでロックされたピースも正しくライン消し判定に入る

## 検収基準
- [x] ソフトドロップが速く、得点が 1 セル 1 点で加算される
- [x] ハードドロップで即座に着地し、落下セル数に応じた得点(+2/セル)が加算される
- [x] ハードドロップでロックされたピースも正しくライン消し判定に入る

## 検証
- `e2e/04-soft-hard-drop.test.ts`（Playwright + TypeScript）でソフトドロップ 6 件・ハードドロップ 5 件を確定的に検証済み。
  - ソフトドロップ: 1 セル/1 点・連続加算・ロックされない・最下部・固定セル・ゲームオーバー
  - ハードドロップ: 着地ロック + 2 点/セル・落下距離による加算・落下得点＋ライン消し得点・ライン消し判定・ゲームオーバー
