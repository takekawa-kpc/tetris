# 004 ソフト / ハードドロップ

- 区分: v1 / 依存: 003 / 状態: ⬜ 未着手

## ゴール

`↓` でソフトドロップ、`Space` でハードドロップができる。

## 実装内容

- [ ] `↓`: 1 セル落下 + 1 点(反復長押し可)。最下部では直ちにロック
- [ ] `Space`: 着地まで即落下 + 2 点/落下セル + 即ロック
- [ ] Space のページスクロール抑制

## テスト(Playwright)

- [ ] `↓` 5 回で 5 セル落下し、スコアが +5
- [ ] `Space` で即着地ロック、加算点が落下セル数 × 2
- [ ] Space 実行中にページがスクロールしない

## 完了条件
