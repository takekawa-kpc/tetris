# 004: ソフトドロップ / ハードドロップ

**ラベル**: feature, v1
**ステータス**: ⬜ 未着手
**関連仕様**: spec.md §2.3, §2.5

## 概要
手動での落下操作(ソフトドロップ・ハードドロップ)と得点を実装する。

## 要求
- [ ] `↓` でソフトドロップ: 1 セル下へ移動し、1 セルにつき 1 点加算する
- [ ] `Space` でハードドロップ: 着地位置まで即時落下してロックし、落下セル数 × 2 点加算する
- [ ] ソフトドロップ中は移動・回転操作も有効
- [ ] ハードドロップ後のロック処理は、落下ループによるロックと同一(ライン消し・出現へ進む)

## 検収基準
- [ ] ソフトドロップが通常の落下より速く、得点が 1 セル 1 点で加算される
- [ ] ハードドロップで即座に着地し、落下距離に応じた得点(+2/セル)が加算される
- [ ] ハードドロップでロックされたピースも正しくライン消し判定に入る
