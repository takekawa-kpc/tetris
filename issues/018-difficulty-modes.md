# 018: 難易度モード

**ラベル**: feature, roadmap
**ステータス**: ⬜ 未着手
**関連仕様**: spec.md §8.8

## 概要
マラソン / スプリント / ウルトラの 3 モードを追加する。

## 要求
- [ ] ゲーム開始前にモードを選択できる(既定: マラソン)
- [ ] スプリント: 50 行を消すとゲームクリア(勝利画面)となる
- [ ] ウルトラ: 3 分間タイムアタックで、経過時間を画面に表示する
- [ ] モードごとのハイスコアを `tetris.highScore.<mode>` で別管理する

## 検収基準
- [ ] 各モードの終了条件(行到達 / 時間経過 / 積み上がり)が正しく判定される
- [ ] モード別のハイスコアが互いに干渉せず更新される
- [ ] モード選択が結果画面とハイスコア表示に正しく反映される
