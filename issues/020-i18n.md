# 020 言語切替

- 区分: roadmap(§10.10) / 依存: 019 / 状態: ⬜ 未着手
- 仕様根拠: spec.md §10.10

## ゴール

UI 文言を日本語 / 英語で切り替える。

## 実装内容

- [ ] 文言をラベル辞書へ集約(現在表示中の全文字列)
- [ ] 切替トグルと `tetris.lang` 保存、既定はブラウザ言語から推定
- [ ] `document.lang` と aria ラベルにも反映

## テスト(Playwright)

- [ ] 切替後、主要ラベル(score 等)が英語になる
- [ ] リロード後に表示言語が復元される

## 完了条件

切替・復元の e2e が green。
