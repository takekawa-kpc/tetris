# 020: 多言語対応(日本語 / 英語)

**ラベル**: feature, roadmap
**ステータス**: ⬜ 未着手
**関連仕様**: spec.md §8.10

## 概要
日本語(既定)/ 英語の切り替えに対応する。

## 要求
- [ ] 全テキスト(ラベル・ボタン・オーバーレイ)を i18n キーに置き換える
- [ ] 日本語(既定)/ 英語を UI から切替可能にする
- [ ] 切替状態を `tetris.locale` キーに保存し、リロード後も維持する
- [ ] 数字・記号の表示(スコア・時刻)がロケールに合わせて整形される

## 検収基準
- [ ] 英語に切替後、画面内の日本語テキストが残らない
- [ ] 切替がリロード後も保持される
- [ ] 切替時にレイアウトの崩れ(文字幅差)が発生しない
