# 010: UI / デザインとアクセシビリティ

**ラベル**: feature, v1, a11y
**ステータス**: ⬜ 未着手
**関連仕様**: spec.md §4, §5

## 概要
レイアウト・デザイン(ダークモード)・アクセシビリティを整備する。

## 要求
- [ ] 盤面中央、左にホールド、右に次のピース(3 個)+ スコアパネルのレイアウト(§4.1)
- [ ] 盤面下部にキー操作ガイドを表示する
- [ ] ダークモード対応(システム設定の `prefers-color-scheme` を追従)
- [ ] ライン消しフラッシュ / スコア変化 / オーバーレイフェードに 150〜300ms のアニメーション
- [ ] スコア・レベル・ハイスコアに `aria-live` を適用する
- [ ] 盤面グリッドは `aria-hidden` として、テキスト情報で状態を補完する
- [ ] キーボードのみで全操作(開始・プレイ・ポーズ・リスタート)が完結できる

## 検収基準
- [ ] PC 画面幅(1024px 以上)でレイアウトが崩れない
- [ ] システムのダークモード切替でテーマが追従する
- [ ] スクリーンリーダーでスコア・ハイスコアの変化が読み上げられる
- [ ] マウスを使わずに 1 周のプレイが完走できる
