## 概要
- Vite + React + Tailwind を使ってシンプルな Tetris を構築しています。
- 4×4 のブロック（I, O, T, S, Z, J, L）を扱い、落下・移動・回転・ソフト/ハードドロップ・ライン消去・スコア＆レベルを実装済みです。
